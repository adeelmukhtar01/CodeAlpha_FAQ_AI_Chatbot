# 🤖 FAQ AI Chatbot

A modern desktop-based **FAQ AI Chatbot** developed using **Python** and **CustomTkinter**. The application is designed to provide quick, accurate, and user-friendly responses to frequently asked questions through an intelligent graphical interface. Instead of relying on hardcoded responses, the chatbot retrieves answers from an Excel-based knowledge base and uses fuzzy text matching to understand user queries, even when they are not typed exactly as stored.

This project demonstrates the practical implementation of Artificial Intelligence concepts in desktop application development while providing an interactive and efficient user experience.

---

# 📌 Project Overview

The FAQ AI Chatbot is a desktop application that allows users to ask questions related to predefined topics. The chatbot intelligently compares the user's input with the available questions stored in an Excel file using the RapidFuzz library and returns the most relevant answer.

The project was developed with a focus on simplicity, usability, and modern interface design, making it suitable for educational demonstrations, academic projects, and small-scale FAQ systems.

# 🧠 Artificial Intelligence Concept

The chatbot utilizes **fuzzy string matching** through the **RapidFuzz** library to identify the closest matching question from the FAQ database. This allows users to receive accurate answers even if their questions contain spelling mistakes, different wording, or slight variations.

Unlike simple keyword matching, fuzzy matching improves the chatbot's ability to understand natural user input and enhances the overall interaction experience.

---

# 📂 Knowledge Base

The chatbot stores all Frequently Asked Questions (FAQs) inside an Excel file.

Each record includes:

- 📁 Category
- ❓ Question
- 🏷️ Keywords
- 💬 Answer

This structure makes the chatbot easy to maintain and allows new questions and answers to be added without modifying the source code.
